Open questions blocking implementation

Each item below conflicts with an existing tinkaria component. Code edits are paused until each lands a choice — see design.md "Dependency Reconciliation" for context.

  1. OQ-1 Two orchestrators in one server. Kanna's subagent-orchestrator.ts (884 LOC) vs tinkaria's c3-206 orchestration / SessionOrchestrator. Recommendation: namespace kanna's as claude-pty/subagent-orchestrator.ts internal to the PTY driver — do not wire it into the global server. Avoids the merge.
  2. OQ-2 kanna-mcp-http.ts + kanna-mcp.ts vs c3-227 extension-router. Recommendation: port verbatim under src/server/claude-pty-mcp/, isolated from extension-router. Re-evaluate consolidation in a follow-up story.
  3. OQ-3 cloudflare-tunnel/ in kanna vs c3-215 share in tinkaria. Recommendation: the PTY driver only needs the type TunnelGateway; satisfy by adapting to c3-215 share's exported type. Do NOT port a second tunnel module.
  4. OQ-4 permission-policy.ts (kanna) vs tinkaria's permission gate. Recommendation: reuse tinkaria's. Adapt PTY driver call sites.
  5. OQ-5 agent.ts normalizers (only 7 functions used from a 3.5k file). Recommendation: re-export the needed symbols from c3-210 agent if already present, otherwise port the 7 functions into src/server/claude-pty/agent-normalizers.ts — do NOT replace tinkaria's agent.ts.
  6. OQ-6 kanna-system-prompt.ts branding. Recommendation: rename "kanna" → "tinkaria" in the prompt text. Behaviour unchanged.
  7. OQ-7 terminal-manager.ts (generic shell terminal). Recommendation: excluded per overview Non-Goals — confirm.
  8. OQ-8 Sandbox follow-up story. Recommendation: open a backlog item to re-evaluate before any non-developer use.

Tradeoffs noted in design.md

  • NATS subject byte stream vs raw WS — picked NATS for transport consistency at the cost of slightly higher per-byte overhead vs raw WS pipes.
  • No sandbox — accepted security risk per user; documented in ADR. Re-evaluation trigger: any non-localhost deployment.
  • Full dep port — heaviest possible scope; reconciliation table contains the only knobs that keep the surface bounded.

Deviations from kanna

  • Sandbox subtree (12 files) not ported.
  • terminal-manager.ts (generic terminal) not ported.
  • WebSocket layer replaced by NATS subjects (no ws-router).
  • Rename: anywhere "kanna" appears as a brand/identifier in ported files, rename to "tinkaria" (logs, prompts, settings keys) unless the symbol is a stable filename used as an interop key with the claude CLI (e.g. ~/.claude/sessions/<pid>.json remains unchanged because claude owns that path).
